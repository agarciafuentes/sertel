# Practica 1 - HTML y CSS

## Servicios Telematicos

Este repositorio contiene la resolucion de la Practica 1 de la asignatura de Servicios Telematicos.

### Contenido
- \Index.html\: Pagina principal de la habitacion (Smart Room).
- \config.html\: Formulario de configuracion de sensores y alertas.
- \minombre.html\: Configuracion de usuario en LocalStorage.
- \css/\: Estilos CSS.

### Tecnologias
- HTML5 Semantico
- CSS3
- JavaScript (Validacion y LocalStorage)
